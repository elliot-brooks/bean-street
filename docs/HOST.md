# Host

You run the floor. The goal is not realism. The goal is momentum.

## Controls

- `Randomize Market`: starts with a chaotic board instead of the flat opening state.
- `Trigger Random Event`: fires a surprise story, either bean-specific or market-wide.
- `Mark Bean Sold`: applies a selloff to one selected bean.
- `Mark Beans Traded`: boosts two selected beans together.
- `Reset Market`: returns everything to the opening state.

## What To Watch

- The headline shows the current top story.
- The ticker repeats the latest summary lines.
- The board ranks beans by current value.
- Each card shows value, latest move, momentum, sentiment, and previous value.

## Simple Run Of Show

1. Start with `Randomize Market` if you want immediate drama.
2. Read the headline and top mover out loud.
3. Use `Trigger Random Event` to keep the room reacting.
4. Use selloffs and trades when you want a specific payoff.
5. Reset between rounds.

## Useful Limits

- Only the 4 most recent events stay active.
- Values are relative multipliers, not money.
- A bean cannot be traded with itself.
- Refreshing the page wipes the current session.
